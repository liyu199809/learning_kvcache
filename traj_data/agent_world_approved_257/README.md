# Agent-World coaching candidates

This snapshot contains 257 reviewed correction rounds from 224 public Agent-World questions. It includes 249 rounds retained after disclosure review, 4 rounds approved after archived-trace regrading, and 4 rounds from the reviewed recovery pilot.

Each line in `agent-world-approved-257.jsonl` is a JSON object with tool schemas, messages before the correction, teacher advice, student continuation, and audit metadata. Use `candidate` as the unique row ID. A reviewed correction can address part of a task, so use `full_rescue` and `verifier_false_pass` when interpreting outcomes.
